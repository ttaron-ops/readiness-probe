Onethe vocabulary

Socket, die, core, thread

socket
A physical slot on the motherboard holding one processor package. Two sockets means two packages, two sets of memory controllers, and a link between them. This is the level on-prem intuition usually stops at.
package
What goes in the socket. On modern AMD parts it contains several chiplets plus an I/O die; on Intel it may be one monolithic die or several tiles. One package, many dies.
die / CCD / tile
A single piece of silicon inside the package. It matters because cores on one die share an L3 slice and a path to memory that cores on another die do not.
core
An independent execution engine with its own L1 and L2. This is the unit the scheduler places a task on.
thread / SMT
Two hardware threads sharing one core's execution units and caches. Doubles the CPU count Linux reports without doubling throughput — and on latency-critical GPU host threads it is often disabled precisely because sharing an L1 with a neighbour adds jitter.
memory controller
Lives on the package and owns a set of DDR channels. This is what makes NUMA physical: memory hangs off a controller, the controller belongs to a package, so some memory is nearer than other memory.

The gap, measured on this machine

Cache is not an optimisation someone bolted on. It exists because DRAM latency has barely improved for two decades while clock speeds did, so a core that waits for memory wastes hundreds of cycles. ThreeDRAM

DIMMs, channels, and the purchase-order mistake

DIMM
A physical memory stick. Capacity lives here; bandwidth does not.
channel
An independent path between the memory controller and DIMMs. Bandwidth scales with channels, and this is the number that matters.
rank
A set of DRAM chips on a DIMM addressed together. Two ranks per channel let the controller overlap operations; more ranks can slightly lower the achievable clock.
DDR5-4800
The transfer rate — 4,800 mega-transfers per second per channel. Multiply by 8 bytes per transfer for per-channel bandwidth.

The one sentence to carry into 02b.1

NUMA is not only about where memory is. On a GPU host, the accelerator, the NIC and the NVMe each have a home socket too, fixed in silicon when the board was seated. Lesson 02b.1 calls this "a PCIe device has a home NUMA node the same way a page does — but fixed at boot, not decided by first touch."

And node count is not socket count

AMD's NPS and Intel's Sub-NUMA Clustering both split one socket into several NUMA domains, so a 2-socket box can report 2, 4 or 8 nodes. That is lesson 02b.1 §6 — just know now that NUMA node(s): 8 does not mean eight processors.

FivePCIe

Enough to read the tree

lane
One differential pair each way. Bandwidth is per-lane rate × lane count, so x16 is four times x4.
root complex
The CPU's entry point to PCIe. It is part of the package — which is precisely why an endpoint has a home socket.
root port
One downstream port on the root complex. A slot usually hangs off one root port.
switch
A fan-out chip: one upstream port, several downstream. Devices under the same switch can talk peer-to-peer through its crossbar without touching the CPU — the entire basis of GPUDirect.
endpoint
The device itself — GPU, NIC, NVMe.
BDF
Bus:Device.Function, e.g. 0000:1b:00.0. The address the OS uses. Same bus number usually means same branch, which is a heuristic for locality, not a guarantee.
   CPU package
     └── root complex          ← belongs to ONE socket
          ├── root port ──── PCIe switch ──┬── GPU0      ┐ same switch:
          │                                ├── NIC0      │ peer-to-peer
          │                                └── NVMe0     ┘ via the crossbar
          └── root port ──── GPU1                          (GPUDirect works)

   GPU0 → NIC0   : one switch hop, never reaches the CPU       PIX
   GPU0 → GPU1   : up to the root complex and back down        PXB / PHB
   GPU0 → socket1: across the inter-socket link                SYS

The "PCIe history" the module skips, in one line

Each generation doubles the per-lane rate — Gen3 ≈ 1 GB/s per lane per direction, Gen4 ≈ 2, Gen5 ≈ 4, Gen6 ≈ 7.6. That is the whole history you need. Lesson 02b.3 does the encoding, the loss budget, and how to spot a link that trained low.

Sixthe rack

Datacenter vocabulary, briefly

U / RU
Rack unit, 1.75 inches. A rack is typically 42U. An 8-GPU server is usually 6–10U, so you fit four to six per rack — before power.
ToR
Top-of-rack switch. Every server in the rack cables to it; the ToR cables up to the fabric. This is the “leaf” in lesson 09's fat tree.
PDU
Power distribution unit — the rack's power strip, and the thing that actually runs out.
hot / cold aisle
Racks face each other so cold air is drawn in the front and exhausted out the back into a shared hot aisle. Determines how much heat a rack may produce.
PUE
Power Usage Effectiveness — total facility power ÷ IT power. 1.2 means 20% overhead for cooling and losses. It multiplies every watt in your cost model.
Check yourselfbefore 02b.1

Drills

lscpu reports 256 CPUs. What is the machine?

Almost certainly 2 sockets × 64 cores × 2 SMT threads. The identity is CPUs = sockets × cores/socket × threads/core, and all three factors are printed.

It matters because "pin to 8 CPUs" means 4 physical cores if SMT is on — half the execution resources you might have assumed.

Why does the same loop run 85× slower on a bigger array?

The working set stopped fitting in a cache level. Measured here: 1.78 ns at 16 KiB (L1), 7.22 ns at 1 MiB (L2), 150.65 ns at 256 MiB.

Flat while it fits, a cliff each time it stops fitting. Same instructions, same complexity class — only the data size changed.

A co-tenant is thrashing cache. Which of your caches can it actually evict?

L3 only — shared_cpu_list shows L1 and L2 are per-core while L3 spans the socket.

So a neighbour on a different core cannot touch your L1 or L2, but can absolutely evict your L3 working set. That is the mechanism behind "cache-hostile co-tenant," and it is why cpuset pinning helps less than people expect.

Same capacity, 4 DIMMs or 8. Does it matter?

Enormously. Bandwidth scales with populated channels, not with gigabytes. Eight channels of DDR5-4800 is ~307 GB/s; four is ~154 GB/s.

Same RAM, half the bandwidth, and unfixable without opening the box. This is decided on a purchase order.

Does a GPU have a NUMA node?

Yes. The root complex is part of a CPU package, so every PCIe endpoint hangs off exactly one socket — fixed in silicon when the board was seated, not chosen at runtime.

A GPU reading a buffer in the other socket's memory crosses the inter-socket link on every transfer.

Two devices under the same PCIe switch. Why does that matter?

They can transfer peer-to-peer through the switch crossbar without the data reaching the CPU or host memory. That is what makes GPUDirect RDMA and GPUDirect Storage fast paths.

nvidia-smi topo -m prints this as PIX. If they are on different root ports you get PXB/PHB; different sockets gives SYS, and the fast path is gone.

How many 8-GPU nodes fit in a 42U rack?

By rack units, four to six. By power, often one. An 8×H100 node draws roughly 10 kW and a conventional rack is provisioned for 10–15 kW.

High-density GPU halls provision 40–100+ kW per rack with liquid cooling. The binding constraint is watts and heat, not space.
